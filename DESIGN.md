# Design System & Guidelines

## Register
design

## Platform
web (Responsive: Mobile / Tablet / Desktop)

## Design Principles
1. **Modern Minimalist (Dark & Sleek)**: โทนสีมืดที่สะอาดตา เน้น Typography และ Hierarchy ที่ชัดเจน
2. **Interactive & Engaging**: Micro-interactions, Smooth Scroll, Responsive Cards, และ Toggle ภาษา (TH/EN)
3. **Glanceable Information**: จัดกลุ่มข้อมูลการทำงาน ทักษะ และผลงานให้สแกนอ่านได้รวดเร็ว
4. **Performance First**: รองรับ Next.js App Router, Optimized Images, และ Tailwind CSS

## Color Palette
- **Background**: Dark Zinc / Slate (`#09090b`, `#18181b`)
- **Card Surfaces**: Deep Charcoal (`#121215`, `#27272a`)
- **Accent Colors**:
  - Indigo / Blue (`#3b82f6`, `#6366f1`): สำหรับ State Enterprise / Trust
  - Emerald / Green (`#10b981`): สำหรับ Active Status & Gas Logistics
  - Amber / Orange (`#f59e0b`): สำหรับ Highlights & Hospitality POS
- **Text**: White (`#ffffff`), Zinc 300 (`#d4d4d8`), Muted Zinc 500 (`#71717a`)

## Typography
- Font Family: Inter / Prompt / Sarabun สำหรับรองรับภาษาไทยและอังกฤษอย่างลงตัว
