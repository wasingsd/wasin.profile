# Wasin Profile & Portfolio — Project Guidelines

> Guidelines and development context for Wasin Garnsomdee's Personal Portfolio & Project Dashboard.

---

## Project Overview
- **Project**: Wasin Profile / Portfolio & Project Showcase
- **Tech Stack**: Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4, Lucide Icons
- **Deployment**: Vercel / GitHub Pages
- **Purpose**: Showcase enterprise project management experience, digital transformation initiatives, and full-stack software architecture.

---

## Key Principles
1. **Clean Code & Modern React**: Utilize React Server Components where appropriate, and keep client interactivity modular.
2. **Bilingual Support (TH/EN)**: Maintain consistent copy in both Thai and English across content dictionaries.
3. **Responsive Design**: Ensure impeccable presentation across Mobile, Tablet, and Desktop screen sizes.
4. **Fast Performance**: Minimize bundle size and optimize asset loading.
